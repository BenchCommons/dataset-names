# legacy/

Este diretório guarda as listas e os scripts originais do repositório: `first_names.all.txt`, `last_names.all.txt` e `generate/`. Os arquivos foram movidos sem alteração da raiz do repositório.

## Licença

O arquivo `DATA_LICENSE` (CC BY 4.0) na raiz vale apenas para o dataset construído pelo pacote `namesio` a partir das fontes declaradas em `sources.yaml`.

O conteúdo de `legacy/` não recebe nenhuma concessão de licença além dos termos das fontes originais de que provém, entre elas os datasets do IMDb, que têm termos não comerciais. Veja `docs/adr/0001-licenca-dos-dados.md`.
